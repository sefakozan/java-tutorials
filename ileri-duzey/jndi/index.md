# Özel Kılavuz: JNDI - İsim ve Dizin Arayüzü (Java Naming and Directory Interface)

**JNDI (Java Naming and Directory Interface)**, Java uygulamalarının birden çok adlandırma ve dizin hizmetine (LDAP, DNS, RMI Registry, Dosya Sistemi, Kurumsal Veritabanı Havuzları) birleşik ve standart bir API üzerinden erişmesini sağlayan bir Java uzantısıdır.

---

## Bu Kılavuzdaki Dersler

### 1. [İsimlendirme İşlemleri (Naming Operations)](ileri-duzey/jndi/naming.md)
`Context` ve `InitialContext` arayüzlerini, isim-nesne bağlama (`bind`), arama (`lookup`), yeniden adlandırma ve silme işlemlerini açıklar.

### 2. [Dizin İşlemleri ve LDAP (Directory Concepts & LDAP)](ileri-duzey/jndi/directory.md)
Öznitelik tabanlı dizin hizmetlerini (`DirContext`), `Attributes` yönetimini ve LDAP sunucuları üzerinde arama filtreleri (`search`) çalıştırmayı inceler.
