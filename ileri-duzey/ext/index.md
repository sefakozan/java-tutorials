# Kılavuz: Eklenti Mekanizması (The Extension Mechanism)

Eklenti mekanizması, Java platformunun temel işlevselliğini genişletmek için standart ve pratik bir yöntem sunar.

---

## Bu Kılavuzdaki Dersler

### 1. [Eklenti Mekanizmasına Giriş](ileri-duzey/ext/index.md)
Eklentilerin amacı ve Java sınıf yükleyici hiyerarşisi içindeki yeri.

### 2. [Kurulu Eklentiler Oluşturma (Installed Extensions)](ileri-duzey/ext/installed.md)
JAR dosyalarını `lib/ext` dizinine yerleştirerek tüm uygulamaların erişimine açma.

### 3. [İndirilebilir Eklentiler (Downloadable Extensions)](ileri-duzey/ext/download.md)
JAR manifest (`MANIFEST.MF`) dosyası ile bağımlı eklenti tanımlama.

### 4. [Eklentileri Güvenli Hale Getirme (Making Extensions Secure)](ileri-duzey/ext/security.md)
Güvenlik politikası (`java.policy`) dosyası ile eklentilere özel izinler atama.
