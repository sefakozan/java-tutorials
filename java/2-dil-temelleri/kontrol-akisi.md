# Kontrol Akış İfadeleri (Control Flow Statements)

Kaynak dosyalarınızdaki ifadeler genellikle göründükleri sırayla, yukarıdan aşağıya doğru yürütülür. Ancak kontrol akışı ifadeleri, karar verme, döngü ve dallanma kullanarak yürütme akışını kesintiye uğratır ve programınızın belirli kod bloklarını koşullu olarak yürütmesini sağlar. Bu bölümde Java programlama dili tarafından desteklenen karar verme ifadeleri (*if-then, if-then-else, switch*), döngü ifadeleri (*for, while, do-while*) ve dallanma ifadeleri (*break, continue, return*) açıklanmaktadır.
