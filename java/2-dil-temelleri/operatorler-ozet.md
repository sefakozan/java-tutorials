# Operatörlerin Özeti (Summary of Operators)

Aşağıdaki hızlı başvuru, Java programlama dili tarafından desteklenen operatörleri özetlemektedir.

## Basit Atama Operatörü (Assignment Operator)
&emsp; <span style="display: inline-block; width: 38px;"><strong>=</strong></span> Basit atama operatörü

## Aritmetik Operatörler (Arithmetic Operators)
&emsp; <span style="display: inline-block; width: 38px;"><strong>+</strong></span> Toplama operatörü (String birleştirme için de kullanılır)  
&emsp; <span style="display: inline-block; width: 38px;"><strong>-</strong></span> Çıkarma operatörü  
&emsp; <span style="display: inline-block; width: 38px;"><strong>*</strong></span> Çarpma operatörü  
&emsp; <span style="display: inline-block; width: 38px;"><strong>/</strong></span> Bölme operatörü  
&emsp; <span style="display: inline-block; width: 38px;"><strong>%</strong></span> Mod alma (Kalan) operatörü

## Birli Operatörler (Unary Operators)
&emsp; <span style="display: inline-block; width: 38px;"><strong>+</strong></span> Tekli artı operatörü; pozitif değeri belirtir (ancak sayılar bu olmadan da pozitiftir)  
&emsp; <span style="display: inline-block; width: 38px;"><strong>-</strong></span> Tekli eksi operatörü; bir ifadeyi olumsuzlar  
&emsp; <span style="display: inline-block; width: 38px;"><strong>++</strong></span> Artırma operatörü; değeri 1 artırır  
&emsp; <span style="display: inline-block; width: 38px;"><strong>--</strong></span> Azaltma operatörü; değeri 1 azaltır  
&emsp;&thinsp; <span style="display: inline-block; width: 38px;"><strong>!</strong></span>Mantıksal tümleme operatörü; bir boolean değerinin değerini tersine çevirir

## Eşitlik ve İlişkisel Operatörler (Equality and Relational Operators)
&emsp; <span style="display: inline-block; width: 38px;"><strong>==</strong></span> Eşittir  
&emsp; <span style="display: inline-block; width: 38px;"><strong>!=</strong></span> Eşit değildir  
&emsp; <span style="display: inline-block; width: 38px;"><strong>></strong></span> Büyüktür  
&emsp; <span style="display: inline-block; width: 38px;"><strong>>=</strong></span> Büyük veya eşit  
&emsp; <span style="display: inline-block; width: 38px;"><strong><</strong></span> Küçüktür  
&emsp; <span style="display: inline-block; width: 38px;"><strong><=</strong></span> Küçük veya eşit

## Koşullu Operatörler (Conditional Operators)
&emsp; <span style="display: inline-block; width: 38px;"><strong>&&</strong></span> Mantıksal VE  
&emsp; <span style="display: inline-block; width: 38px;"><strong>||</strong></span> Mantıksal VEYA  
&emsp; <span style="display: inline-block; width: 38px;"><strong>? :</strong></span> Üçlü (if-then-else ifadesinin kısa yazımı)

## Tür Karşılaştırma Operatörü (Type Comparison Operator)
&emsp; <strong>instanceof</strong> &nbsp; Bir nesneyi belirtilen bir türle karşılaştırır

## Bit Düzeyinde ve Bit Kaydırma Operatörleri (Bitwise and Bit Shift Operators)
&emsp; <span style="display: inline-block; width: 38px;"><strong>~</strong></span> Birli bitsel tümleyen  
&emsp; <span style="display: inline-block; width: 38px;"><strong>&lt;&lt;</strong></span> İşaretli sola kaydırma  
&emsp; <span style="display: inline-block; width: 38px;"><strong>&gt;&gt;</strong></span> İşaretli sağa kaydırma  
&emsp; <span style="display: inline-block; width: 38px;"><strong>&gt;&gt;&gt;</strong></span> İşaretsiz sağa kaydırma  
&emsp; <span style="display: inline-block; width: 38px;"><strong>&</strong></span> Bitwise VE  
&emsp; <span style="display: inline-block; width: 38px;"><strong>^</strong></span> Bitwise özel VEYA  
&emsp; <span style="display: inline-block; width: 38px;"><strong>|</strong></span> Bitwise VEYA
