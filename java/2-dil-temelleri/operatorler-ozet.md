# Operatörlerin Özeti (Summary of Operators)

## Operatör Önceliği Tablosu (Operator Precedence)

Operatörler öncelik sırasına göre aşağıda listelenmiştir. En yüksek önceliğe sahip operatörler tablonun en üstünde yer alır:

| Operatörler | Öncelik / Açıklama |
| :--- | :--- |
| **Sonek (*Postfix*)** | `ifade++` `ifade--` |
| **Birli (*Unary*)** | `++ifade` `--ifade` `+ifade` `-ifade` `~` `!` |
| **Çarpımsal (*Multiplicative*)** | `*` `/` `%` |
| **Toplamsal (*Additive*)** | `+` `-` |
| **Kaydırma (*Shift*)** | `<<` `>>` `>>>` |
| **İlişkisel (*Relational*)** | `<` `>` `<=` `>=` `instanceof` |
| **Eşitlik (*Equality*)** | `==` `!=` |
| **Bit Düzeyinde VE (*Bitwise AND*)** | `&` |
| **Bit Düzeyinde XOR (*Bitwise XOR*)** | `^` |
| **Bit Düzeyinde OR (*Bitwise OR*)** | `|` |
| **Mantıksal VE (*Logical AND*)** | `&&` |
| **Mantıksal OR (*Logical OR*)** | `||` |
| **Üçlü (*Ternary*)** | `? :` |
| **Atama (*Assignment*)** | `=` `+=` `-=` `*=` `/=` `%=` `&=` `^=` `|=` `<<=` `>>=` `>>>=` |
