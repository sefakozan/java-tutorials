# Sınıflar Hakkında Daha Fazlası (More on Classes)

Bu bölüm, nesneler hakkındaki önceki bölümlerde öğrendiğiniz nesne referanslarını ve nokta (`.`) operatörünü kullanmaya dayanan sınıfların diğer yönlerini kapsar:

* Metotlardan değer döndürme (Returning values from methods).
* `this` anahtar kelimesi (The `this` keyword).
* Sınıf üyelerine karşı örnek üyeleri (Class vs. instance members).
* Erişim kontrolü (Access control).
