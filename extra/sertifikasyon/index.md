# Kılavuz: Java Programlama Dili Sertifikasyonu için Hazırlık

Oracle Java Sertifikasyon programı, geliştiricilerin Java programlama dilindeki yetkinliklerini uluslararası düzeyde kanıtlamalarını sağlar.

---

## Sertifikasyon Seviyeleri

1. **Oracle Certified Associate (OCA):** Java dilinin temelleri, nesne yönelimli programlama, kontrol akışları, temel API'ler ve istisna yönetimi konularını kapsar.
2. **Oracle Certified Professional (OCP):** Generics, koleksiyonlar, ileri düzey eşzamanlılık (concurrency), NIO.2 dosya işlemleri, veritabanı erişimi (JDBC) ve modern Java özelliklerini kapsayan ileri düzey sınavdır.

---

## Temel Çalışma Konuları

- Java Dil Temelleri ve Veri Tipleri
- Nesne Yönelimli Tasarım İlkeleri (Kapsülleme, Kalıtım, Polimorfizm, Soyutlama)
- Fonksiyonel Programlama ve Lambda İfadeleri
- Java Koleksiyon Çerçevesi (JCF) ve Streams API
- Eşzamanlılık ve Çok İş Parçacıklı Programlama
- G/Ç Akışları ve NIO.2 Dosya Sistemi
- Tarih ve Saat API'leri (`java.time`)
- Güvenlik ve İstisna Yönetimi
