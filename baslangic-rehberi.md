# The Java™ Tutorials - Kılavuz Dizini

The Java Tutorials, Java programlama dilini kullanarak uygulamalar geliştirmek isteyen programcılar için pratik kılavuzlardır. Yüzlerce eksiksiz, çalışan örnek ve onlarca ders içerir. İlgili ders grupları "kılavuzlar" (trails) halinde düzenlenmiştir.

---

## 1. Temel Konuları Kapsayan Kılavuzlar (Trails Covering the Basics)

- **[Başlarken (Getting Started)](baslarken/index.md)** — Java teknolojisine giriş, Java geliştirme yazılımını kurma ve bunu basit bir program oluşturmak için kullanma dersleri.
- **[Java Dilini Öğrenmek (Learning the Java Language)](java/index.md)** — Java Programlama Dilinin temel kavramlarını ve özelliklerini anlatan dersler.
- **[Temel Java Sınıfları (Essential Java Classes)](essential/index.md)** — İstisnalar (Exceptions), temel giriş/çıkış (I/O), eşzamanlılık (Concurrency), düzenli ifadeler (Regex) ve platform ortamı dersleri.
- **[Koleksiyonlar (Collections)](collections/index.md)** — Java Koleksiyon Çerçevesini (Java Collections Framework) kullanma ve genişletme dersleri.
- **[Tarih-Saat API'leri (Date-Time APIs)](datetime/index.md)** — Tarih ve saat kodları yazmak için `java.time` paketlerinin nasıl kullanılacağı.
- **[Dağıtım (Deployment)](deployment/index.md)** — Uygulamaların JAR dosyaları kullanılarak nasıl paketleneceği ve dağıtılacağı.
- **[Java Programlama Dili Sertifikasyonu Hazırlığı](extra/sertifikasyon/index.md)** — Mevcut eğitim ve öğretici kaynakların listesi.

---

## 2. Grafiksel Kullanıcı Arayüzleri Oluşturma (Creating Graphical User Interfaces)

- **[Swing ile GUI Oluşturma (Creating a GUI with Swing)](gui/swing.md)** — Java platformunda grafiksel kullanıcı arayüzü (GUI) oluşturmaya kapsamlı bir giriş.
- **[JavaFX ile GUI Oluşturma (Creating a JavaFX GUI)](gui/javafx.md)** — Modern JavaFX öğreticileri koleksiyonu.

---

## 3. Özel Kılavuzlar ve Dersler (Specialized Trails and Lessons)

- **[Özel Ağ Programlama (Custom Networking)](ileri-duzey/networking/index.md)** — Java platformunun güçlü ağ iletişimi özelliklerine (TCP/IP, UDP, URL) giriş.
- **[Eklenti Mekanizması (The Extension Mechanism)](ileri-duzey/ext/index.md)** — Özel API'lerin Java platformunda çalışan tüm uygulamalar için nasıl erişilebilir hale getirileceği.
- **[Tam Ekran Özel Mod API'si (Full-Screen Exclusive Mode API)](ileri-duzey/fullscreen/index.md)** — Kullanıcının grafik donanımından daha kapsamlı yararlanan tam ekran uygulamalar geliştirme.
- **[Genel Türler - İleri Düzey (Generics)](ileri-duzey/generics/index.md)** — Derleme zamanı tip güvenliği sağlayan gelişmiş jenerik desenler, joker karakterler ve kurallar.
- **[Uluslararasılaştırma ve Yerelleştirme (Internationalization - i18n)](ileri-duzey/i18n/index.md)** — Yazılımların farklı dillere ve coğrafi bölgelere kolayca uyarlanabilmesi için tasarım ilkeleri.
- **[JavaBeans Bileşen Teknolojisi](ileri-duzey/javabeans/index.md)** — Java platformunun yeniden kullanılabilir yazılım bileşeni standardı.
- **[JAXB ile XML Bağlama (Java Architecture for XML Binding)](ileri-duzey/jaxb/index.md)** — Java sınıfları ile XML şemaları arasında otomatik nesne eşleme.
- **[JAXP ile XML İşleme (Java API for XML Processing)](ileri-duzey/jaxp/index.md)** — DOM, SAX ve StAX ile XML belgelerini okuma, işleme ve dönüştürme.
- **[JDBC ile Veritabanı Erişimi (JDBC Database Access)](ileri-duzey/jdbc/index.md)** — Java uygulamaları ile ilişkisel veritabanları arasında bağlantı ve SQL sorgulama API'si.
- **[JMX - Java Yönetim Uzantıları (Java Management Extensions)](ileri-duzey/jmx/index.md)** — Uygulamaları, cihazları ve servisleri MBean nesneleri ile merkezi olarak izleme ve yönetme.
- **[JNDI - İsim ve Dizin Arayüzü (Java Naming and Directory Interface)](ileri-duzey/jndi/index.md)** — DNS, LDAP ve kurumsal adlandırma servislerine erişim arayüzü.
- **[Reflection - Yansıma API'si](ileri-duzey/reflection/index.md)** — JVM içindeki sınıfları, arayüzleri ve nesneleri dinamik olarak inceleme ve çağırma.
- **[RMI - Uzaktan Metot Çağırma (Remote Method Invocation)](ileri-duzey/rmi/index.md)** — Farklı Java Sanal Makinelerinde çalışan nesneler arasında uzaktan metot çalıştırma.
- **[Güvenlik Mimarisi (Security)](ileri-duzey/security/index.md)** — Uygulamaları kötü amaçlı yazılımlardan korumaya yönelik izinler, şifreleme ve yetkilendirme altyapısı.
- **[Sockets Direct Protokolü (SDP)](ileri-duzey/sdp/index.md)** — InfiniBand yüksek hızlı donanımından yararlanmak için Sockets Direct Protokolünü etkinleştirme.
- **[Ses API'si (Sound)](ileri-duzey/sound/index.md)** — Uygulamalardan ses verilerini (WAV, MIDI) çalma, kaydetme ve işleme API'si.
- **[2B Grafikler (2D Graphics - Java 2D)](ileri-duzey/2d/index.md)** — İki boyutlu şekiller, degradeler, geometrik dönüşümler ve yazdırma işlemleri.
